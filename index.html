Jev Mailbox Cleaner

A personal, self-hosted email screening tool.

Privacy Policy Terms of Service

Jev Mailbox Cleaner is a private, self-hosted application built and operated by its developer for personal use. It connects to the developer's own Gmail account(s) via Google OAuth, classifies inbox messages against a set of custom rules using an AI classification API, and — only when a rule is explicitly set to "live" mode — moves or archives matching messages.

This is not a public product, is not distributed to other users, and does not collect or process data belonging to anyone other than its own developer.
