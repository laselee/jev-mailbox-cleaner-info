Privacy Policy

Last updated: 2026-09-28

Jev Mailbox Cleaner is a personal, self-hosted application built, deployed, and used solely by its developer. It is not offered as a service to the public and does not have other end users. This policy explains what the application does with data from the Gmail account(s) it is connected to.

What data is accessed

When connected to a Gmail account via Google OAuth (scope: https://www.googleapis.com/auth/gmail.modify), the application reads the subject, sender, and body text of messages in that account's inbox, and can add/remove Gmail labels or archive messages on that account.

How the data is used

Message subject, sender, and body text are sent to a third-party AI classification API (TypeSafe / Jev) solely to evaluate them against user-defined rules (for example, "is this a promotional email?"). No data is used for advertising, profiling, or any purpose other than classifying the developer's own inbox contents against rules the developer configured.

Where the data is stored

Classification results and Gmail OAuth credentials are stored locally in a SQLite database on infrastructure the developer owns and operates (a self-hosted Docker container). Credentials are encrypted at rest. Nothing is stored on, or transmitted to, any server operated by a third party other than the classification API call described above.

Data sharing

Data is not sold, shared, or disclosed to any third party except the classification API call described above, which is necessary for the application's core function.

Data retention and revocation

Data is retained for as long as the developer continues to operate the application. Access can be revoked at any time from Google Account → Third-party access, which immediately stops the application from accessing the account.

Contact

Questions about this policy can be sent to the developer contact address listed on this application's Google Cloud OAuth consent screen.
